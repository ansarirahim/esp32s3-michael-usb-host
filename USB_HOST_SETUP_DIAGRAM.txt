WHAT HAPPENS:
- Computer provides power and serial monitor to ESP32-S3
- Computer sees ESP32-S3 as CDC device (COM port) - NORMAL!
- ESP32-S3 controls USB flash drive via USB-OTG port
- ESP32-S3 formats, copies files, and ejects the flash drive
- Firmware operates in USB HOST mode

=============================================================================
ESP32-S3 USB INTERFACES EXPLAINED
=============================================================================

The ESP32-S3 has TWO separate USB interfaces:

1. USB-Serial-JTAG (Built-in Debug Interface)
   ┌─────────────────────────────────────────┐
   │ Purpose: Programming, Debugging, Logs   │
   │ Pins: GPIO 19, GPIO 20                  │
   │ Appears as: CDC device (COM port)       │
   │ Used for: Serial monitor (PuTTY)        │
   │ Always active when connected to PC      │
   └─────────────────────────────────────────┘

2. USB-OTG (USB Host/Device Interface)
   ┌─────────────────────────────────────────┐
   │ Purpose: USB Host or USB Device         │
   │ Pins: GPIO 19, GPIO 20 (shared!)        │
   │ Current mode: USB HOST                  │
   │ Used for: Controlling USB flash drives  │
   │ Requires: OTG resistor shorted          │
   └─────────────────────────────────────────┘

NOTE: Both interfaces share GPIO 19/20, but serve different purposes!


=============================================================================
USB HOST MODE vs USB DEVICE MODE
=============================================================================

USB HOST MODE (Current Firmware):
----------------------------------
    ESP32-S3 (HOST)  ←→  USB Flash Drive (DEVICE)
         ↓
    Controls the flash drive
    Formats, copies files, ejects


USB DEVICE MODE (Not implemented):
-----------------------------------
    Computer (HOST)  ←→  ESP32-S3 (DEVICE)
         ↓
    ESP32-S3 appears as USB drive
    Computer can read/write files

=============================================================================
TROUBLESHOOTING
=============================================================================

SYMPTOM: "I see CDC device when connecting to computer"
CAUSE: USB-Serial-JTAG interface (normal!)
SOLUTION: This is expected. Connect USB flash drive to USB-OTG port.

SYMPTOM: "Files get copied but eject doesn't work"
CAUSE: Misunderstanding - eject works on flash drive, not ESP32
SOLUTION: Check serial output for eject messages. If present, it's working!

SYMPTOM: "Cannot switch to MSC device mode"
CAUSE: Firmware is USB HOST mode only
SOLUTION: This is correct per requirements. No change needed.

SYMPTOM: "USB flash drive not detected"
CAUSE: OTG resistor not shorted, or wrong USB port
SOLUTION: 
  1. Short OTG resistor/jumper on board
  2. Connect flash drive to USB-OTG port (not debug port)
  3. Check serial output for detection messages
